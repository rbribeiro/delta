Revolutionizing Scientific Diffusion

Delta is a markup language based on web technologies for creating dynamic math papers, books, and presentations. Bring your scientific work to life with interactive elements, beautiful layouts, and seamless integration of HTML, CSS, and JavaScript.

Get Started

Main Features

Dynamic Content

Embed interactive math, code, and visualizations directly into your papers and presentations.

Beautiful Layouts

Leverage modern web design for stunning, responsive documents and slides.

Web Technology Powered

Use HTML, CSS, and JavaScript for full customization and extensibility.

How to Get Started

  1. 1. Install Delta via npm: npm install delta-markup
  2. 2. Write your first .delta file using familiar web syntax.
  3. 3. Render and share interactive documents with the Delta CLI or web app.
  4. 4. Explore the documentation for advanced features.
