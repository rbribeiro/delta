System Architecture

Delta follows a layered architecture separating language parsing, semantic transformation, and output rendering.

Frontend Layer (HTML + CSS)

Browser-based editor, preview engine, syntax highlighting, and UI logic.

Core Engine (Java Script)

Lexer, parser, abstract syntax tree, semantic analyzer, and transformation pipeline.

Export Pipeline (Python)

PDF rendering, slide generation, LaTeX bridges, and automation tooling.

Setup & Installation

This section describes how to run Delta locally for development or deployment.

Requirements

  • Modern web browser (Chrome, Firefox, Safari)
  • Python 3.9+
  • Node.js (optional, for frontend tooling)

Local Installation


git clone https://github.com/rbribeiro/delta.git
cd delta

# Start backend engine
./gradlew run

# Start frontend (optional dev server)
npm install
npm run dev

Using Delta

Write once — export everywhere. This section introduces the basic workflow.

1. Write

Author structured content using Delta blocks such as theorems, proofs, definitions, examples, and exercises.

2. Preview

Instantly preview how your document renders as lecture notes or slides.

3. Export

Generate PDFs, slides, web pages, and academic papers with a single click.

proof.delta
Open editor 
theorem "Fundamental Theorem of Calculus":
  statement:
    Let f be continuous on [a,b].
  proof:
    By the mean value theorem...

proof:
  Vamos demonstrar este teorema fundamental passo a passo.
  step "Configuração inicial":
    Seja $S = \{x \in [a,c] : f(x) < k\}$. Este conjunto é limitado superiormente por b.
    hint:
      O conjunto S é não-vazio pois $a \in S$ (assumindo $f(a) < k$).
  step "Aplicação do supremo":
    Por ser limitado superiormente, S possui supremo. Seja $c = \sup(S)$.
    hint:
      Lembre-se que todo conjunto limitado superiormente possui supremo nos reais.

API & Internal Interfaces

Delta exposes internal APIs between its frontend, compiler engine, and export pipeline.

Frontend → Engine

JSON-based AST transport for real-time compilation and preview rendering.

Engine → Exporters

Structured intermediate representation consumed by Python export modules.

CLI Interface

Command-line tooling for batch conversion and automated workflows.
