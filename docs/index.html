Why Delta

The web already has everything a smarter paper needs.

Delta began with a frustration. Its creator — a mathematician — was tired of flattening living ideas into static PDF: a theorem you can't unfold, a figure you can't touch, a reference that's just a number on the page.

Yet the web solved this years ago. Interaction, motion, math that renders, links that actually link — every ingredient of a smarter paper has been sitting right there. Papers just never moved to it.

So Delta brings them across — without giving up what makes a paper a paper: rigor, numbering, citations. You write in a familiar LaTeX-like markup and Delta does the web for you — no JavaScript to learn, no front-end to build. Made by mathematicians and students, for scientists and students. Install

Install the CLI, build your paper.

Delta is a command-line tool that runs on Node.js (which bundles npm). Install Node for your system, then install Delta from npm.

1 · Install Node.js 
# download the LTS installer from nodejs.org, or use winget:
> winget install OpenJS.NodeJS.LTS

# then check it worked
> node -v && npm -v
# download the LTS installer from nodejs.org, or use Homebrew:
$ brew install node

# then check it worked
$ node -v && npm -v
# install Node.js + npm from apt
$ sudo apt update
$ sudo apt install nodejs npm

# then check it worked
$ node -v && npm -v
2 · Install Delta
terminal 
# install the Delta CLI from npm
$ npm install -g delta-lang

# build a document
$ delta build paper.dlt -o paper.html

# ...or a whole multi-file project
$ delta build project.toml
What Delta looks like

Familiar markup in, a living document out.

Author with simple tags and inline $math$, the way you'd write LaTeX. Delta numbers it, renders the math, and turns it into an interactive document.

hello.dlt 
<theorem id="thm:pyth">
  <title>Pythagorean Theorem</title>
  <meta>
    <meta-item key="Author">Pythagoras</meta-item>
  </meta>
  For a right triangle with legs $a$, $b$
  and hypotenuse $c$,
  <equation id="eq:pyth">a^2 + b^2 = c^2</equation>
</theorem>
→ renders to
Theorem 1.1 Pythagorean Theorem

For a right triangle with legs a, b and hypotenuse c,

a2 + b2 = c2(1.1)
AuthorPythagoras

And the result comes to the reader: by Theorem 1.1Theorem 1.1 — Pythagorean Theorem. For a right triangle with legs a, b and hypotenuse c, a2 + b2 = c2. the legs decide the hypotenuse — hover it and read the statement in place, no scrolling back.
