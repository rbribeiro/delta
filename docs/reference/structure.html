Structure

The skeleton of every .dlt file: the <document> root, the <title> that names things, numbered <section>s, and an auto <toc>.

<document> Document

The root element — exactly one per file. Its attributes set the language, the document type (which picks a theme), and the look (accent hue, dark mode, an author stylesheet). Everything else nests inside it.

Attributes
AttributeTypeRequiredDescription
langBCP-47optionalDocument language (default en); drives i18n labels and <html lang>.
typearticle · book · presentationoptionalSelects the type theme (default article).
themename · pathoptionalA built-in theme (impatech), or a path to your own stylesheet.
theme-accenthue nameoptionalAccent palette: blue, purple, …
theme-modedark · autooptionalDark palette (or follow the OS).
paper.dlt 
<document lang="en" type="article">
  <title>My Paper</title>
  <section id="intro">
    <title>Introduction</title>
    Hello, world.
  </section>
</document>
→renders to
My Paper
1 Introduction

Hello, world.

See also theme, <slide>.

<title> Title

Names whatever contains it — the document, a section, or an environment. Always the first child. The compiler hoists it into the right heading at render time, so you never pick a heading level; the surrounding tag decides. May contain inline math and emphasis.

Attributes
AttributeTypeRequiredDescription
None — <title> takes no attributes; its meaning comes from its parent.
title.dlt 
<section id="limits">
  <title>Limits and $\epsilon$</title>
  …
</section>
→renders to
2 Limits and ε

…

See also <section>, <theorem>.

<section> Sectioning

Numbered, nestable headings. The family is <chapter>, <section>, <subsection>, and <subsubsection> — each carries a <title> and gets an automatic number like 2.1. Add collapsible to let readers fold a section away.

Attributes
AttributeTypeRequiredDescription
idstringoptionalAnchor so <ref> and the ToC can link here (auto-slugged if omitted).
collapsibletrueoptionalMake the heading a fold toggle.
collapsedtrueoptionalStart folded (implies collapsible).
section.dlt 
<section id="methods">
  <title>Methods</title>
  <subsection>
    <title>Sampling</title>
    …
  </subsection>
</section>
→renders to
2 Methods
2.1 Sampling

…

See also <toc>, <ref>.

<toc> Table of contents

Drop it anywhere and Delta builds a table of contents from the document's headings — each entry links to its section. In a multi-file project, scope="project" lists the whole book and links across files.

Attributes
AttributeTypeRequiredDescription
depthnumberoptionalDeepest heading level shown (default 2 = down to subsections).
scopeprojectoptionalList every file's headings, not just this one's.
toc.dlt 
<toc/>
→renders to
  • 1 Introduction
  • 2 Methods
  • 2.1 Sampling
  • 3 Results

See also <section>.
