Reference

Environments

Numbered, boxed blocks for the parts of an argument — theorems, definitions, proofs. The whole theorem family shares one counter, just like \newtheorem{lemma}[theorem] in LaTeX, so numbering stays consistent across kinds.

<theorem> Theorem family

A numbered theorem box. The same shape gives you <lemma>, <proposition>, <corollary>, <conjecture>, <claim>, and <observation> — all sharing the theorem counter. Give it an id so a <ref> can point at it; add a <title> and optional <meta> for the header.

Attributes
AttributeTypeRequiredDescription
idstringoptionalAnchor for <ref> / the hover preview.
collapsibletrueoptionalLet readers fold the box.
<title>childoptionalThe named title shown in parentheses.
<meta>childoptionalAuthor/source lines under the statement.
theorem.dlt 
<theorem id="thm:pyth">
  <title>Pythagorean Theorem</title>
  <meta>
    <meta-item key="Author">Pythagoras</meta-item>
  </meta>
  For a right triangle with legs $a$, $b$
  and hypotenuse $c$,
  <equation id="eq:pyth">a^2 + b^2 = c^2</equation>
</theorem>
→renders to
Theorem 1.1 Pythagorean Theorem

For a right triangle with legs a, b and hypotenuse c,

a2 + b2 = c2(1.1)
AuthorPythagoras

See also <proof>, <meta>, <ref>.

<definition> Definition, example, remark

Same box, different counters: <definition>, <example>, <remark>, <exercise>, and <problem> each number independently of the theorem family. Use them to mark out the supporting pieces of an argument.

Attributes
AttributeTypeRequiredDescription
idstringoptionalAnchor for <ref>.
<title>childoptionalOptional named title.
definition.dlt 
<definition id="def:open">
  <title>Open set</title>
  A set $U$ is open if every point has a
  neighbourhood contained in $U$.
</definition>
→renders to
Definition 1.2 Open set

A set U is open if every point has a neighbourhood contained in U.

See also <theorem>.

<proof> Proof

An unnumbered block led by an italic Proof. and closed with a tombstone (∎). With of="id" it links back to the result it proves; <solution> works the same way for exercises. Add collapsed="true" to fold it until the reader wants it.

Attributes
AttributeTypeRequiredDescription
ofidoptionalThe theorem/exercise this proves; adds a back-link.
collapsible · collapsedtrueoptionalFold the proof away.
proof.dlt 
<proof of="thm:pyth">
  Drop the altitude and compare the two
  similar triangles it creates.
</proof>
→renders to

Proof. Drop the altitude and compare the two similar triangles it creates. ∎

See also <theorem>.

<meta> Metadata

A small key/value block that renders under an environment's statement — for an author, a source, a year. Each row is a <meta-item key="…">; <author> is a shorthand for the common case.

Attributes (on <meta-item>)
AttributeTypeRequiredDescription
keystringrequiredThe label shown for the row.
meta.dlt 
<meta>
  <meta-item key="Author">Euclid</meta-item>
  <meta-item key="Source">Elements, I.47</meta-item>
</meta>
→renders to
AuthorEuclid SourceElements, I.47

See also <theorem>.
