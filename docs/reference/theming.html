Theming & files

Recolor with an accent, switch to dark mode, supply your own stylesheet, add custom-element packs, and split a work across files.

theme Theme

Sets the document's whole look. The value is either the name of a built-in theme that ships with Delta, or a path to a stylesheet of your own — Delta tells them apart by shape, so you never have to say which you meant.

How the value is read
You writeDelta reads it asWhy
theme="impatech"a built-in themeA bare name — letters, digits and dashes only.
theme="my.css"a file next to your documentIt has a dot.
theme="../shared/brand.css"a file at that pathIt has a separator.

A bare name is never looked for on disk, so a stray file can't change how your document renders, and a misspelled name tells you so — listing the themes that do exist — instead of failing with a confusing “file not found”. An unknown theme is a warning, never a failed build: the document still compiles, in the default look.

Built-in themes
NameLook
impatechModern and high-contrast: signage lime with amber / pink / mint, a near-white page, pure-black type, large rounded corners, flat (no shadows), sans throughout.

Themes compose rather than conflict. theme-accent and theme-mode still apply on top of a built-in, and your own stylesheet still overrides it — so you can start from a built-in and change only the last mile:

talk.dlt
<document theme="impatech" theme-mode="dark" theme-accent="pink">

See also <document>.

Writing your own theme

A theme is a set of --delta-* custom properties. Delta's own components are written entirely against these, so re-valuing them restyles everything at once — you never need to target Delta's internal classes.

The tokens come in two tiers. Swatches are the raw colour vocabulary (--delta-sand-50…800 and --delta-char-50…800, two warm neutral ramps). Roles are what components actually read — re-point a role and the whole system follows. Dark mode is nothing more than the roles re-pointed from the light ramp onto the dark one.

The roles you will reach for most
TokenRole
--delta-paper · --delta-surface-1 · --delta-surface-2Page and card backgrounds.
--delta-ink · --delta-ink-soft · --delta-muteText, from body copy down to captions.
--delta-rule · --delta-rule-softBorders and dividers.
--delta-accent · --delta-accent-ink · --delta-accent-softThe accent as a fill, as readable text, and as a wash. Pick -ink by hand: a colour bright enough to fill with is rarely dark enough to read.
--delta-serif · --delta-sans · --delta-monoFont families. --delta-serif is the prose family — body text and headings both ask for it — so a sans-first theme re-points it too.
--delta-weight-display · --delta-weight-strongHeading weight and bold weight.
--delta-radius-sm · --delta-radius · --delta-radius-lg · --delta-radius-pillCorner rounding.
--delta-elevationShadow strength. Set it to 0 for a flat design and it stays flat in dark mode too.

Environments (theorem, definition, example, …) have their own small set, so you can restyle them without touching every other card in the document. Each family carries a tone, used to fill its label pill and — scaled by --delta-env-tint — to colour its border. Give each family a different tone and a reader can tell a theorem from a definition while scanning, which is worth a great deal in a long document:

Environment tokens
TokenRole
--delta-env-bg · --delta-env-borderThe box interior and its edge.
--delta-tone-theorem · --delta-tone-definition · --delta-tone-example · --delta-tone-remark · --delta-tone-exerciseOne tone per family. Default: the page colour, i.e. the quiet outlined pill.
--delta-env-tag-ink · --delta-env-tag-borderThe pill's text and outline. Filling a pill with a tone usually means black text and no outline.
--delta-env-tintHow far the box border is pulled toward its family tone — 0 (default) neutral, 1 the tone itself.
--delta-numSection and equation numbers. Colouring these is a cheap way to add accent without touching running prose.

Keep colour out from behind running prose. A document may be read for hours, so the reading surface wants to stay neutral — put the colour in the small, repeated pieces (pills, numbers, rules), which is what the tokens above are for.

Derive tinted colours from a role rather than from a fixed colour — color-mix(in oklab, var(--delta-accent) 24%, var(--delta-paper)) re-derives itself correctly when the page turns dark, where a hard-coded tint would not.

What a theme should not set. Leave --delta-page-pad-x, --delta-page-pad-y, --delta-col-gap, --delta-section-gap and --delta-block-gap alone: Delta shrinks them at each breakpoint, and a fixed value would defeat that. If you must change --delta-t-base, use a clamp() so it stays responsive.
