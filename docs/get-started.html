Get started

From zero to a living document.

Install the Delta CLI, write a few tags, and compile a single, fully offline HTML file you can open anywhere. Then wire up the VS Code extension for live preview.

About 5 minutes · needs only Node.js

1

Install the CLI

Delta is a command-line tool that runs on Node.js 20 or newer (which bundles npm). Install Node for your system, then install Delta from npm.

Install Node.js 
# download the LTS installer from nodejs.org, or use winget:
> winget install OpenJS.NodeJS.LTS

# then check it worked
> node -v && npm -v
# download the LTS installer from nodejs.org, or use Homebrew:
$ brew install node

# then check it worked
$ node -v && npm -v
# install Node.js + npm from apt
$ sudo apt update
$ sudo apt install nodejs npm

# then check it worked
$ node -v && npm -v
Install Delta
terminal 
# installs the `delta` (and `dlt`) command globally
$ npm install -g delta-lang
Heads up

The package is delta-lang; it gives you a delta command (and a short dlt alias). Running delta with no arguments prints the usage.

2

Write your first page

A Delta document is strict XML. Create paper.dlt with a <document> root, a <title>, and a <section>. Write inline math between $…$ just like LaTeX, and wrap results in an environment like <theorem>.

paper.dlt 
<document lang="en" type="article">
  <title>My First Paper</title>

  <section id="intro">
    <title>Introduction</title>
    Delta turns strict XML into a single offline HTML file.
    Inline math like $e^{i\pi} + 1 = 0$ just works.

    <theorem id="thm:pyth">
      <title>Pythagorean Theorem</title>
      For a right triangle with legs $a$, $b$ and hypotenuse $c$,
      <equation id="eq:pyth">a^2 + b^2 = c^2</equation>
    </theorem>
  </section>
</document>
→renders to

Delta turns strict XML into a single offline HTML file. Inline math like eiπ + 1 = 0 just works.

Theorem 1.1 Pythagorean Theorem

For a right triangle with legs a, b and hypotenuse c,

a2 + b2 = c2(1.1)

That's the whole model: tags you already recognize, math where you'd expect it. Browse the structure, environments, and math references for everything you can drop in.

3

Compile it

Build the document into one self-contained HTML file — no external CSS, JS, or fonts — then open it straight from disk. It works fully offline, even from file://.

terminal 
# compile paper.dlt → paper.html
$ delta build paper.dlt -o paper.html

# …or omit -o and Delta writes paper.html next to the source
$ delta build paper.dlt

Pass --watch while you write and Delta rebuilds on every save:

terminal 
$ delta build paper.dlt -o paper.html --watch

Splitting a larger work across files? List them, or point Delta at a project.toml — they compile as one numbered work with shared cross-references:

terminal 
# several files → an output directory
$ delta build intro.dlt methods.dlt results.dlt -o out/

# …or drive it from a project file
$ delta build project.toml
4

Edit in VS Code

The Delta VS Code extension adds .dlt syntax highlighting, build-on-save, inline error diagnostics, and a live preview that refreshes as you type. It isn't on the Marketplace yet, so build it from source:

terminal 
# 1 · the extension shells out to the CLI — make sure it's installed
$ npm install -g delta-lang

# 2 · clone the extension and package it into a .vsix
$ git clone https://github.com/rbribeiro/delta-vs-extension
$ cd delta-vs-extension
$ npm install
$ npx @vscode/vsce package

# 3 · install the .vsix into VS Code
$ code --install-extension delta-lang-0.0.1.vsix
Tip

You can also install the .vsix from the Extensions panel (⋯ → Install from VSIX…), or just open the cloned folder in VS Code and press F5 to launch it in a development host.

Then open any .dlt file: with delta.buildOnSave on (the default) the extension starts a watch build automatically. Open the Command Palette (Ctrl/Cmd+Shift+P) and run Delta: Open Preview for a live, auto-refreshing view beside your source; use Delta: Restart Watcher if you ever need to reset it. Point delta.path at a specific CLI, or flip delta.preview.openOnBuild to open the preview automatically.
